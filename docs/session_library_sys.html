Standard Library

System Calls & Environment

std::env (Environment & Arguments)

The std::env module allows inspection and manipulation of the process's environment.

  • env::args() - Returns an iterator of the command line arguments that the process was started with.
  • env::var("PATH") - Fetches the environment variable key from the current process.
  • env::set_var("KEY", "VALUE") - Sets the environment variable key to the value string.
  • env::current_dir() - Returns the current working directory as a PathBuf.
  • env::set_current_dir(&path) - Changes the current working directory to the specified path.

std::process (Process Execution)

The std::process module provides a way to spawn child processes and interact with them.

  • Command::new("ls") - Constructs a new Command for launching the program at path.
  • cmd.arg("-l") - Adds an argument to pass to the program.
  • cmd.envs(map) - Adds multiple environment variables to the new process.
  • cmd.spawn() - Executes the command as a child process, returning a handle to it.
  • cmd.output() - Executes the command as a child process, waiting for it to finish and collecting all of its output.
  • process::exit(1) - Terminates the current process with the specified exit code.

Tutorial Highlight: Executing a System Command

use std::process::Command;

fn main() {
    let output = Command::new("ls")
        .arg("-la")
        .output()
        .expect("Failed to execute command");

    println!("Output: {}", String::from_utf8_lossy(&output.stdout));
}
