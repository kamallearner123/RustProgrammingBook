Setup Guide

Pre-Workshop Requirements

To ensure we can hit the ground running, all students must complete the following setup steps before attending the workshop. This will give you the complete Rust toolchain and a properly configured development environment.

Course Prerequisites

To use this course efficiently and get the most out of the hands-on labs, students should meet the following 5 prerequisites:

  • 1. Basic C/C++ Concepts: A fundamental understanding of C/C++ syntax, particularly how pointers, arrays, and manual memory management (malloc/free) work.
  • 2. Hardware Requirements: A modern laptop or desktop (Windows, macOS, or Linux) with at least 8GB of RAM and a stable internet connection for downloading packages.
  • 3. Software Environment: The complete Rust toolchain (rustc, cargo, and rustup), along with Visual Studio Code (configured with the rust-analyzer extension) or Visual Studio with Rust support.
  • 4. Terminal Familiarity: Basic comfort with using a command-line interface (CLI) to navigate directories and execute build scripts.
  • 5. Security Mindset: A general interest in cybersecurity concepts, such as why memory leaks and data races represent severe vulnerabilities.

1. Install Rust (rustup, cargo)

Rust is installed and managed by a tool called rustup. The installation process depends on your operating system.

For Linux and macOS

Open a terminal and run the following command to download and execute the rustup installation script:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
Program 1: For Linux and macOS

When prompted, press 1 for the default installation. After installation completes, you may need to restart your terminal or run source $HOME/.cargo/env to update your system's PATH.

For Windows

On Windows, Rust requires the Microsoft C++ Build Tools for compilation.

  1. Download and run rustup-init.exe from rustup.rs.
  2. If you don't already have the C++ build tools installed, the installer will prompt you. It is highly recommended to follow the prompt and let it install the Visual Studio C++ Build tools automatically.
  3. Once the build tools are ready, the Rust installation terminal will appear. Press 1 for the default installation and hit Enter.

2. IDE and Environment Setup

  • Install Visual Studio Code: Download and install VS Code from code.visualstudio.com.
  • Install Rust Analyzer Extension: Open VS Code, go to the Extensions tab (Ctrl+Shift+X / Cmd+Shift+X), search for "rust-analyzer", and install it. This provides essential autocomplete and language support.
  • Download workshop exercise files: Ensure you have downloaded or cloned the provided exercise repository to your local machine before the first session.
  • SESSION 5: Test your skills (50 MCQs)

3. Verify Installation ("Hello, World!")

To confirm everything is working properly, open a fresh terminal (or PowerShell on Windows) and run the following commands sequentially:

cargo new hello_world
cd hello_world
cargo run
Program 2: 3. Verify Installation ("Hello, World!")

If your installation was successful, the code will compile and you will see Hello, world! printed to the terminal.

Need Help? If you encounter any issues during the installation, please reach out to the instructor prior to the start of the workshop.
