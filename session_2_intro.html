Session 2

Basics of Rust programming

Welcome to Session 2! Now that we've seen the dangers of unmanaged memory, it's time to learn how Rust solves these problems without sacrificing performance. This crash course covers the essential syntax and paradigms you need to know.

Topics Covered

  • 2.1 Variables

    Learn about Rust's default immutability and how it enforces safe state modifications.

  • 2.2 Data Types

    Understand Primitive vs Non-Primitive data types, and how the compiler uses them to ensure memory safety.

  • 2.3 Functions

    Understand function signatures, types, and implicit returns.

  • 2.4 Ownership

    The core feature of Rust. Learn the three rules of ownership that eliminate the need for a garbage collector.

  • 2.5 Borrowing

    How to safely pass data around without transferring ownership.

  • 2.6 References

    Deep dive into references and the dereferencing operator.

  • 2.7 Mutable vs Immutable

    The golden rule of references that mathematically prevents Data Races at compile time.

  • 2.8 Error Handling

    Discover how Rust forces you to handle errors explicitly using the Result enum and the ? operator.

  • 2.9 Cargo Basics

    Master the standard Rust build system and package manager.
