Session 2.5

References and Dereferencing

Overview & Syntax

We saw how borrowing uses references (&). A reference is like a pointer in C/C++: it holds a memory address. However, unlike C pointers, Rust references are guaranteed to point to a valid value of a particular type for the life of that reference.

When you have a reference, sometimes you need to access the underlying value directly. You do this using the dereference operator, which is the asterisk (*).

Example 1: Basic Dereferencing

View C/C++ Buggy Code 

// C Null Pointer Dereference
// C references (pointers) can be NULL, causing immediate crashes.
void update_score(int *score_ptr) {
    // If the developer forgets: if (score_ptr == NULL) return;
    // The server will instantly crash with a Segfault.
    *score_ptr = *score_ptr + 10;
}
                        
fn main() {
    let x = 5;
    let y = &x; // y is a reference to x

    assert_eq!(5, x);
    assert_eq!(5, *y); // Dereference y to get the value
}

Output: (The program runs silently because the assertions pass.)

Why: y holds the memory address of x. To compare the integer 5 against y, we must follow the reference to the value it points to using *y.

Example 2: Error - Comparing Integer to Reference

fn main() {
    let x = 5;
    let y = &x;

    if x == y { // ERROR: can't compare `{integer}` with `&{integer}`
        println!("Equal!");
    }
}

Error Explanation: Rust enforces strict typing. An integer (i32) and a reference to an integer (&i32) are completely different types. You cannot directly compare a value to a memory address.

Example 3: Modifying via Mutable Reference

fn main() {
    let mut x = 5;
    let y = &mut x; // Create a mutable reference

    *y += 1; // Dereference to modify the underlying value

    println!("The value is now: {}", x);
}

Why: To change the value that a mutable reference points to, we must dereference it first using *y. Then we can mutate the underlying data.

Knowledge Check (MCQ)

Question: What operator is used to follow a reference to the actual data it points to?

  1. & (Ampersand)
  2. * (Asterisk)
  3. -> (Arrow)
  4. # (Hash)

Answer: B. The asterisk (*) is the dereference operator in Rust.
