Session 2.2

Rust Data Types

Rust is a statically typed language, which means that it must know the types of all variables at compile time. While the compiler can usually infer what type we want to use, understanding the exact type taxonomy is critical for memory safety.

(Please ensure 'rust_types.png' is saved in your project folder)

Primitive Data Types

Primitive types are basic data structures built directly into the language. They live directly on the Stack (because they have a known, fixed size at compile time).

Scalar Types

A scalar type represents a single value. Rust has four primary scalar types:

  • Integers: Numbers without a fractional component. They can be Signed (i8, i16, i32, i64, i128, isize) which can hold negative numbers, or Unsigned (u8, u16, u32, u64, u128, usize) which only hold positive numbers. The isize and usize types depend on the architecture of the computer your program is running on (64-bit or 32-bit).
  • Floating-Point Numbers: Numbers with decimal points. Rust provides f32 (single-precision) and f64 (double-precision).
  • Character (char): Represents a single Unicode scalar value. Unlike C (where a char is 1 byte), a Rust char is 4 bytes and can represent emojis, accented letters, and non-Latin scripts.
  • Boolean (bool): Represents a logical state: true or false.

⚠️ C/C++ Developer Trap: No Implicit Type Coercion

In C, you can seamlessly add a char to an int, or pass a float into a function expecting a double. The compiler implicitly converts it. Rust refuses to do this. If you try to add an i32 to an i64, the compiler will throw an error. You must explicitly cast types using the as keyword (e.g., x as i64). This eliminates an entire class of subtle integer overflow and truncation vulnerabilities.

Compound Types

Compound types can group multiple values into one type.

  • Tuples: A collection of values of different types. They have a fixed length. Example: (i32, f64, char).
  • Arrays: A collection of elements of the same type, with a fixed length. Example: [i32; 5] is an array of exactly 5 integers.

Non-Primitive Data Types (Containers)

Non-primitive types (often part of the standard library) usually point to dynamically sized data on the Heap, or they are advanced constructs used to manage state safely.

  • String: A dynamically sized, UTF-8 encoded, growable text container.
  • Vector (Vec<T>): A dynamically sized, growable array.
  • Enums: Types that can be one of several variants (like Option and Result).
  • HashMap: A collection of key-value pairs.
  • References: Pointers to data owned by another variable (e.g., &str, &i32).
  • Smart Pointers: Like Box, Rc, and Arc, which provide advanced memory management capabilities.

Knowledge Check

Question: What is the main difference between a C char and a Rust char?

Answer: A C char is just 1 byte (ASCII). A Rust char is 4 bytes. This allows Rust to natively support Unicode scalar values (like emojis and global alphabets), preventing common internationalization parsing bugs.
