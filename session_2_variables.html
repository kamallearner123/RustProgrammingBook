Session 2.1

Variables in Rust

Overview & Syntax

In Rust, variables are declared using the let keyword. By default, variables in Rust are immutable, meaning once a value is bound to a name, you cannot change that value. This is a core feature that drives safety and concurrency in Rust.

Syntax: let variable_name = value;

To make a variable mutable, you must explicitly use the mut keyword: let mut variable_name = value;

Example 1: Immutable Variables

View C/C++ Buggy Code 

// In C, variables are mutable by default.
// It is very easy to accidentally overwrite a critical configuration value.
int max_retries = 3;
// ... hundreds of lines later ...
max_retries = -1; // Accidental logic bug, no compiler warning!
                        
fn main() {
    let x = 5;
    println!("The value of x is: {}", x);
}

Why: We bind the value 5 to x. The compiler infers the type (i32 by default) and prints it successfully.

Example 2: Compiler Error on Mutation

fn main() {
    let x = 5;
    println!("The value of x is: {}", x);
    x = 6; // ERROR: cannot assign twice to immutable variable `x`
    println!("The value of x is: {}", x);
}

Error Explanation: The Rust compiler will throw an error cannot assign twice to immutable variable. Rust prevents unintended data modification. This guarantees that if a variable is not marked mut, you can be 100% sure it will never change unexpectedly, which eliminates many bugs related to state modification.

Example 3: Mutable Variables

fn main() {
    let mut x = 5;
    println!("The initial value of x is: {}", x);
    x = 6;
    println!("The new value of x is: {}", x);
}

Output:

The initial value of x is: 5
The new value of x is: 6

Why: By adding mut, we explicitly tell the compiler (and other developers) that this variable's value will change in the future. The assignment x = 6 is now completely valid.

Knowledge Check (MCQ)

Question: What is the default state of a variable declared with let in Rust?

  1. Mutable
  2. Immutable
  3. Global
  4. Untyped

Answer: B. Immutable. This default forces you to think carefully about which data needs to change and which doesn't, enhancing security and safety.
