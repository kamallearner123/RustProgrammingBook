Exercise 1

Bank API Auth

Mission Briefing: First National Rust Bank's terminal authentication is currently insecure. Your first task is to build a CLI application that securely captures the teller's name before granting access to the system.

Objective

Build a simple interactive Command Line Interface (CLI) application. This exercise will familiarize you with Cargo, standard input/output, and basic variables.

Project Code

Create a new project by running cargo new bank_auth in your terminal. Then, replace the contents of src/main.rs with the following code:

use std::io; // Import the input/output library

fn main() {
    println!("=== First National Rust Bank ===");
    println!("Terminal Authentication System");
    println!("Please enter your Teller ID or Name:");

    // Create a mutable string to store the input
    let mut teller_name = String::new();

    // Read a line from standard input
    io::stdin()
        .read_line(&mut teller_name)
        .expect("Failed to read input"); // Handle potential OS errors

    // Print the greeting
    println!("Access Granted. Welcome, {} System initialized.", teller_name);
}
Program 26: Project Code

How to Run

Run cargo run in your terminal. You should be prompted to enter your name, and then greeted.

Enhancement Challenges

Modify the code above to accomplish the following:

  1. Trim the Whitespace: You might notice the output has an awkward newline because read_line captures the Enter key. Use the .trim() method on teller_name when printing to fix this.
  2. Handle Empty Strings: If the user hits Enter without typing a name, print "Access Denied!" instead. (Hint: Use an if statement and check teller_name.trim().is_empty()).
  3. Add Color: Add the colored crate to your Cargo.toml dependencies, and use it to print the final greeting in green text.
