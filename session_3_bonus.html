Bonus Project

Secure Password Generator

Objective

Combine everything you've learned to build a fully functional, real-world utility: a secure random password generator. You will use external crates, handle loops, generate random data, and manipulate strings.

Project Setup

Run cargo new pass_gen. Then, add the rand crate to your project by running cargo add rand in the terminal. Your Cargo.toml will update automatically.

Project Code (src/main.rs)

use rand::Rng; // Import the random number generator trait

fn generate_password(length: usize) -> String {
    // The pool of characters to choose from
    let charset = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789!@#$%^&*";
    let mut rng = rand::thread_rng(); // Initialize random generator
    let mut password = String::with_capacity(length);

    for _ in 0..length {
        // Pick a random index between 0 and the length of the charset
        let idx = rng.gen_range(0..charset.len());
        
        // Retrieve the character at that index safely
        // (Note: .nth() is O(n), but fine for small charsets)
        if let Some(ch) = charset.chars().nth(idx) {
            password.push(ch);
        }
    }

    password
}

fn main() {
    println!("Generating a secure 16-character password...");
    let safe_pass = generate_password(16);
    println!("Your new password: {}", safe_pass);
}
Program 35: Project Code (src/main.rs)

How to Run

Run cargo run. Every time you execute it, a brand new secure string will be printed to the terminal.

Enhancement Challenges

Take off the training wheels! Modify the code to accomplish the following:

  1. CLI Arguments: Use std::env::args() so the user can pass the desired password length via the command line (e.g., cargo run -- 24). Don't forget to validate that the input is a valid integer and greater than 8!
  2. Strict Requirements: Right now, it's possible (though unlikely) for the generator to output 16 lowercase letters. Update the logic to guarantee that the final password contains at least one uppercase letter, one number, and one special character.
  3. Dictionary Check: Create a separate text file named banned_words.txt containing words like "password", "admin", and "qwerty". After generating the password, open and parse the file to ensure the generated string doesn't contain any of the banned substrings.
