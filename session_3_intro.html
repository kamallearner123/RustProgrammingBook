Session 3

Lab Exercises

Welcome to the hands-on lab portion of the course! Reading about Rust is great, but the only way to truly understand the compiler is to fight it and win.

🏦 The Mission: Secure the Bank API

You have just been hired as a Lead Security Engineer at First National Rust Bank. The previous C++ engineering team left behind a legacy backend full of memory leaks, buffer overflows, and race conditions. Over the next 6 exercises, you will rewrite their core banking infrastructure from scratch using safe Rust.

Project Roadmap

  • Exercise 1: Bank API Auth (Hello Rust)

    Create a basic interactive CLI application to authenticate the user and log them into the banking terminal.

  • Exercise 2: Transaction Reverser (Ownership)

    Build a string manipulation tool to reverse and audit transaction logs without violating memory ownership rules.

  • Exercise 3: Secure Account Access (Buffer Overflows)

    Replace the vulnerable C++ account indexing logic with secure slices and Option enums.

  • Exercise 4: Transfer Validator (Input Validation)

    Build a robust parser that rejects malicious transfer amount inputs from potential hackers.

  • Exercise 5: Audit Logger (Safe File Handling)

    Read and write banking configuration files safely, ensuring the system doesn't crash if the disk is full.

  • Exercise 6: Global Vault Total (Thread-safe Counter)

    Fix a catastrophic Data Race that occurs when multiple branches try to deposit money simultaneously.

  • Bonus: Secure 2FA Token Generator

    Build a fully-functional, secure CLI password generator for the bank's two-factor authentication system.
